Claiming your project

If you run a project on Giveth, claiming it here lets you read the seeds written to you and answer them.

Open the Giveth door, then I run a project.

Your address. The last part of your project's Giveth link, copied exactly. It is case sensitive: CARE-PERU is not care-peru.

Proving it. Gratus gives you a code and a secret. Put the code anywhere in your project description on Giveth and save it. Then finish the claim: Gratus reads your page back and looks for the code. You can remove the line afterwards.

Why this way. It is the same proof a website uses for a domain. Gratus never has to be told who you are, only shown that you can edit what the project says about itself. Before this, one tap made anyone the steward of any project.

Your key waters seeds for the project. It is shown once and never stored. Keep it.
