When something goes wrong

The garden looks empty. Almost always a different browser or a cleared storage. Try the browser you usually use. If you have an export, restore it.

A gift link will not open. The whole gift is in the link, so a link that was cut short in a message loses part of it. Ask for it again, sent as a link rather than as text.

Voice is not offered. Transcription is not configured on that deployment, or you have reached the day's allowance. Typing always works.

Giveth says a project does not exist. The address is case sensitive and is the last part of the project's own link, copied exactly.

A claim will not finish. Giveth can take a minute to save a description. Wait and try again. The code has to be on the page Gratus reads back.

Something is unreadable. That is a fault, not your eyesight. Open an issue using the template called a word I could not read, and it gets fixed.
