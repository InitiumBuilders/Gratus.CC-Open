Because there is no account, the copy you keep is the copy that exists.

**Export.** Open You from the top bar, then export. You get a file holding your whole
garden: plants, days, entries, folders, milestones, gifts and seeds.

**Keep it somewhere real.** A cloud drive, an email to yourself, anywhere that is not only
this browser.

**Restore.** The same sheet takes the file back. Restoring replaces what is in the browser
with what is in the file.

**When to do it.** Before clearing browser data, before changing phones, and every so often
in any case.

**A new version never eats your garden.** When the app's shape changes, an older garden is
walked forward one step at a time and kept, including from a version this build has never
heard of. It is never discarded for holding the wrong number.
